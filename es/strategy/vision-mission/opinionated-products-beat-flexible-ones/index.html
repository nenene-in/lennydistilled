Definitorio
Los productos de software con carácter son básicamente plataformas de software que tienen integradas mejores prácticas o quizás algunas reglas. Hay sistemas que se pueden personalizar de cualquier manera y como se quiera, y luego hay otros sistemas que imponen una cierta forma de comportarse o de trabajar.
