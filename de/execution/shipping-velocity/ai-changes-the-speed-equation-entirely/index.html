Inbal Shani diskutiert, wie KI-Codiertools die Zeit von Entwicklern freisetzen können, indem sie den Anteil ihrer Arbeitszeit, den sie tatsächlich mit Codeschreiben verbringen, reduzieren.

Die meisten Entwickler verwenden weniger als 25%, manche sagen sogar weniger als 20% ihrer Zeit zum Schreiben von Code. Wenn wir ihnen also eine halbe Stunde zurückgeben, können sie einerseits mehr Code schreiben, andererseits eine Pause machen und durchatmen, so dass wir sie nicht ausbrennen lassen und sie glücklicher sind. Drittens geben wir ihnen mehr Zeit für Zusammenarbeit und kreatives Denken, was Innovationen anregt.
